# MATES Foundation

**Together for a Better Society.**

A complete responsive static website for MATES Foundation, designed around the exact supplied navy-and-teal logo.

## Pages

Home, About, Initiatives, six initiative detail pages, Get involved, Contact, Privacy and a custom 404 page.

## GitHub Pages

The included `.github/workflows/pages.yml` deploys public files from `main`. If GitHub has not enabled Pages yet, open **Settings → Pages → Build and deployment → Source → GitHub Actions**, then rerun the workflow.

Expected address after successful deployment: https://ai4betterair.github.io/MATESFoundation/

## Editing

Page source is generated by `build.py` using only Python's standard library. Edit the copy/templates in `build.py` and run `python build.py`. CSS and JavaScript are in `assets/`. The original supplied PNG is preserved byte-for-byte at `assets/mates-foundation-logo.png`; CSS adjusts its display framing without modifying it.

## Contact and donations

No official contact or payment details were supplied. The contact form prepares copyable/downloadable text locally; it does **not** submit anything. No donations or payments are collected. Replace this with verified contact channels and an appropriate service when available. There are no invented impact numbers, testimonials, registration claims, partners or active-program promises.

## Accessibility and privacy

Responsive layouts, keyboard focus, skip navigation, labelled inputs, mobile menu and reduced-motion support. No analytics, local storage, tracking cookies or third-party JavaScript. Google Fonts loads optional typefaces with system fallbacks.
